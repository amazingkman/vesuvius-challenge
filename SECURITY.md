# Security policy

## Reporting a vulnerability

Please report privately, through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for a security problem.

This covers anything that could expose credentials, identify or reach the owner's machine or accounts, or run untrusted code. It also covers scroll renders or other restricted data in the repository, which we treat the same way.

The rules, threat model and audit log are in [`docs/security.md`](docs/security.md), and the decision behind them is DR-010 in [`docs/decisions.md`](docs/decisions.md).
